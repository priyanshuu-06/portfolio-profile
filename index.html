PROJECT DEEP-DIVE

VANRAKSHAK

Connecting Edge Intelligence with Remote Forest Monitoring.

Vanrakshak explores how forest-fire detection and anti-poaching surveillance can operate effectively in areas with limited or no network connectivity. The system integrates on-device AI inference with long-range LoRa wireless communication to deliver structured alerts without depending on cellular infrastructure.

🌲PHYSICAL ENVIRONMENTForest terrain, fire-risk zones, wildlife corridors
↓
SENSOR LAYERCamera Module · Digital IR Flame Sensor
↓

↓

↓

Hardware Components

  • Raspberry Pi 5 — edge node and gateway
  • LoRa transceiver modules — wireless link layer
  • Camera module — live visual capture
  • Digital IR flame sensor — thermal event detection
  • Power management system

Software & Technologies

  • YOLO — real-time fire detection inference
  • Python — edge processing, sensor handling
  • LoRa protocol — low-bandwidth structured alerts
  • React.js — monitoring dashboard
  • Structured event logging and alert classification
