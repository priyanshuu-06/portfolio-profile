## 📞 Support

### **If something doesn't work:**
1. Hard refresh: `Ctrl + Shift + R`
2. Clear cache: `Ctrl + Shift + Del`
3. Check browser console: `F12`
4. Look for error messages
5. Verify image paths in HTML

### **Common Issues:**

| Issue | Solution |
|-------|----------|
| Images not showing | Check file paths match your folders |
| Animations janky | Browser may be slow; try different browser |
| Scroll effects not working | Scroll to trigger them; disable reduce-motion setting |
| Research tabs not switching | Refresh page; clear cache |
| Mobile looks broken | Pinch zoom in/out or rotate device |
