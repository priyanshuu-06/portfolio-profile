# 🚀 Deploy to GitHub Pages — Your Portfolio

Your portfolio code is now on GitHub! Follow these steps to make it live:

---

## Step 1: Enable GitHub Pages

1. Go to your repository: **https://github.com/priyanshuu-06/portfolio-profile**
2. Click **Settings** (top menu bar)
3. Click **Pages** (left sidebar)
4. Under "Build and deployment":
   - **Source:** `Deploy from a branch`
   - **Branch:** `master` / `/ (root)`
5. Click **Save**

⏱️ Takes 1-2 minutes to deploy

---

## Step 2: Your Portfolio is Now LIVE! ✅

## Check Deployment Status

1. Go to your repo: https://github.com/priyanshuu-06/portfolio-profile
2. Look for the **yellow/green circle** next to recent commits
3. Click it to see deployment status
   - 🟡 Yellow = Building
   - 🟢 Green = Live
   - 🔴 Red = Error

## Troubleshooting

### "404 Not Found" Error
- **Wait 1-2 minutes** for GitHub to build
- Check if Pages is enabled in Settings → Pages
- Hard refresh: `Ctrl+Shift+R`

### Changes Not Showing
- Check that you pushed: `git push`
- Wait 30-60 seconds
- Hard refresh: `Ctrl+Shift+R`
- Check deployment status (green circle)

### Wrong Branch Selected
- Make sure Settings → Pages shows **Branch: master**
- Root folder should be **/ (root)**

## Optional: Custom Domain

Want to use `yourname.com` instead?

1. **Buy a domain** from:
   - GoDaddy
   - Namecheap
   - Google Domains

2. **Configure DNS** to point to GitHub:
   - Add `CNAME` record: `priyanshuu-06.github.io`

3. **Add to GitHub**:
   - Settings → Pages → Custom domain
   - Enter your domain name
   - Save

GitHub auto-generates HTTPS certificate! 🔒
